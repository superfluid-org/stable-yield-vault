# Stable Yield Vault Glossary

## Periods

**epoch** : duration between two rebalancing cycles

**era** : duration between two yield readjustment cycles

## Assets

**asset** : underlying token

**working asset (WA)** : asset currently invested into the strategy and not necessary instantly liquid

**unutilized asset (UA)** : asset currently held by the FundManager (instantly usable)

**depositing asset (DA)** : asset deposited by an investor but not yet accounted for by the vault/fund manager

**redeeming asset (RA)** : asset pending to be withdrawn by an investor

**yield asset (YA)** : asset pending to be distributed as yield to investors
